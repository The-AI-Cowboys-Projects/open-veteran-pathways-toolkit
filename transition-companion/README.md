# Transition Companion

**Built by The AI Cowboys.** The AI Cowboys Foundation, [www.theaicowboysfoundation.org](https://www.theaicowboysfoundation.org), a veteran-owned AI lab in San Antonio.

A separation checklist that links the other three tools and official public pages. Checked steps and an optional date stay in `localStorage` under `ovpt-companion-v1`. Use “Download a backup file” if you want a copy you can move.

The list is a reminder to read official sources. It does not complete TAP and it does not decide a benefit.
