# Scam Guardian

Explainable, on-device checks for messages that target veterans, military families, and older adults. Paste text, or upload a screenshot when the folder is served over HTTP so the local Tesseract worker can run.

The title does not say deepfake. This page does not judge faces, voices, or video. A result is an aid, not a guarantee.

Rules are original and cite public VA, FTC, and FBI pages. A separate hint comes from a small model trained on the 2011 SMS Spam Collection. Scram by Erfan Mirhosseini is credited for the offline-screenshot approach and is not included. See [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
