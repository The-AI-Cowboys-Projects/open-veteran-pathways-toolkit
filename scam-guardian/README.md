# Scam Guardian

**Built by The AI Cowboys.** The AI Cowboys Foundation, [www.theaicowboysfoundation.org](https://www.theaicowboysfoundation.org), a veteran-owned AI lab in San Antonio.

Explainable, on-device checks for messages that target veterans, military families, and older adults. Paste text, or upload a screenshot when the folder is served over HTTP so the local Tesseract worker can run.

The title does not say deepfake. This page does not judge faces, voices, or video. A result is an aid, not a guarantee.

Rules are original and cite public VA, FTC, and FBI pages. A separate hint comes from a small model trained on the 2011 SMS Spam Collection. A point rubric is a second reading. The optional Gemma model is off until a person downloads it.
