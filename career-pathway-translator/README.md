# Career Pathway Translator

Fork and improvement of [Debriefed](https://github.com/csimser/debriefed) (MIT License).

## Purpose
Offline, single-HTML military-to-civilian pathway and resume translator. Integrates Foundation MOS to CEO Translator data, glossary, and guide content.

## Status
Scaffold for Sentient Foundation grant MVP. Full Debriefed source to be integrated and improved with Foundation data.

## Features (planned)
- 33k+ dictionary entries (from Debriefed)
- MOS/AFSC/rating input to civilian pathways
- Resume language generation
- No account, offline-first, private-by-default (localStorage)
- Integration with Foundation free tools
