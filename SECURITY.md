# Security policy

**Built by The AI Cowboys**

The Open Veteran Pathways Toolkit is a set of static files from The AI Cowboys Foundation, [www.theaicowboysfoundation.org](https://www.theaicowboysfoundation.org), a veteran-owned AI lab in San Antonio. There is no account, no server-side session, and no database in this repository.

## Reporting

Report a security problem to contact_us@theaicowboys.com.

Describe the page and what happened. If the report does not describe a working exploit against a person, a GitHub issue is also fine.

Do not include classified information, Controlled Unclassified Information (CUI), protected health information (PHI), or sensitive personally identifiable information (SPII) in the report. Do not paste a real scam message that contains someone else’s data. A short invented example is enough.

If the report describes a working exploit against a person, email contact_us@theaicowboys.com instead of opening a public issue, and still leave out personal data.

## What this repository can and cannot fix

The pages run in the visitor’s browser. A bug in a rule, a dictionary substitution, or a model prompt can be fixed here. A compromised browser, a shared computer, or a malicious browser extension is outside this repository.

The optional Gemma model is not a security product. Its output is a suggestion for a person to review. A low scam score is not a clearance.

## Supported use

Use the files from a current release of this repository, from GitHub Pages, or from a copy you serve yourself. The Foundation is not affiliated with the Department of Defense or the Department of Veterans Affairs.
